Kann man das „polnische Trinkspiel“ schaffen? 

„!!!ACHTUNG!!! DIESES SPIEL HAT NOCH NIEMAND GESCHAFFT“ 

Das sind die Worte, die auf dem Spielplan des „polnischen Trinkspiels“ stehen und für jeden Spieler als Warnung dienen sollen. Doch lässt sich diese Aussage auch bestätigen? In der vorliegenden Arbeit soll genau das untersucht werden. Dafür werden mit einer Monte-Carlo-Simulation Spiele simuliert und die Ergebnisse ausgewertet. Wie viele Schlücke müssen durchschnittlich von jedem Spieler getrunken werden, bis der erste Spieler das Ziel-Feld erreicht?
